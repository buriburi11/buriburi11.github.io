Each one was a course project with an instructor-provided scaffold. The case studies spell out which parts I wrote.

Rate-limited model access gateway

Java 21 · HTTP/1.1 · RFC 868 · WHOIS · Redis RESP2 · virtual threads

An HTTP gateway in front of a language-model endpoint. For every request it asks a Time server for the current minute, then asks WHOIS for the caller's tier and Redis for an atomic usage count at the same time. Only then does it decide whether the model gets called. I framed all four wire protocols by hand over raw sockets.

Reliable file transfer over UDP

Java 21 · sliding window · AIMD · Jacobson/Karels RTO · Karn's algorithm · fast retransmit

TCP's core ideas rebuilt on top of UDP. The sender pushes a file through a proxy that drops, delays and reorders packets, and has to get every byte across anyway. I wrote the sender's protocol logic: the window, the congestion window, the timer, and the loss recovery.

One dropped segment → 3 duplicate ACKs → fast retransmit. I also found and fixed an inverted check that had silently disabled it.

Link-state routing control plane

Java 21 · Dijkstra · forwarding tables · atomic snapshots · JSON over TCP

A control plane for up to 64 routers. When a link goes down it recomputes shortest paths from every router and publishes complete forwarding tables as one generation-numbered snapshot, so a reader never sees half of a network change.

Failover and partition verified across 7 generations; 9/9 unit tests and the end-to-end simulator pass.
